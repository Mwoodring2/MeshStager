MeshStager v0.1.0-rc1 (portable)

1. Unzip this archive to any folder you can write to (for example Desktop or Documents).
2. Open the MeshStager folder.
3. Double-click MeshStager.exe. No separate Python install is required.

Data (settings and logs) are stored under:
  %LOCALAPPDATA%\MeshStager\

If you previously used Roundup, your settings, tags, favorites, caches, and bridge
outputs are migrated automatically on first launch (legacy data under
%LOCALAPPDATA%\Roundup\ is preserved).

This folder is outside the unzipped app, so the program keeps your preferences when you move or replace the app folder.

If the window does not open and you see an error about Qt or platform plugins, the release notes may ask you to use a "full" PySide6 bundle build. Otherwise use this lean build.

For support, see the project README or your internal release page.
